agentBot 接入 X

用 X Peer Bridge（sidecar）把 agentBot 作为互联网上的对等 Agent 实例接入 X：复用 X 连接层，映射 agentBot MCP，支持断线补推、提问、取消与双向互调。

01结论与范围

agentBot 的 role 只是其 MCP 的内部能力，本方案不依赖 role 语义。

采用 X Peer Bridge（sidecar）：bridge 作为 X 的 peer 节点，复用 X 的连接层与协议；对 agentBot 只使用现有 MCP（/mcp）与新增的事件流。

X 看到

一个 kind=agentbot 的 peer；默认单个能力，不展开 role。

agentBot 侧

无需改造成 X 协议；bridge 负责会话映射与结果回流。

反向调用

agentBot 的 opencode 实例加载 plugins/opencode 调 X。

阶段

P1 当前 X v1 可跑通；P2 依赖 X peer v0.2 获得可靠性与流式。

6.2 主流程（P1 轮询）

sequenceDiagram participant X as X节点 participant B as Bridge participant A as agentBot MCP X->>B: session.open(openId, epoch) B->>A: apply_session(role) A-->>B: callerSessionId B-->>X: session.accept(remoteSessionId, features) X->>B: prompt(promptId, text) B->>A: chat(callerSessionId, text, wait=false) A-->>B: taskId B-->>X: prompt_ack(promptId) loop 轮询 B->>A: get_result(taskId) A-->>B: running / waiting_input / done / failed end B-->>X: done(reason, text) 或 error(code, retryable)

6.3 提问 / 取消 / 关闭

stateDiagram-v2 [*] --> RUNNING RUNNING --> WAITING: waiting_input WAITING --> RUNNING: X answer 用同凭证 chat WAITING --> FAILED: 10min 超时 RUNNING --> DONE: get_result done RUNNING --> CANCELLING: X cancel CANCELLING --> CANCELLED: close_session / cancel_task RUNNING --> FAILED: get_result failed DONE --> [*] CANCELLED --> [*] FAILED --> [*]
  • 权限：agentBot 自动拒绝，bridge 不宣告 permission。
  • 取消：P1 回 cancel_ack 后忽略迟到结果；P2 调 cancel_task 中断 opencode。
  • 关闭：session.close → close_session → session.closed。

08部署拓扑

flowchart LR subgraph 公网 X[X 节点 wss://x/peer] end subgraph agentBot主机 BR[Bridge 进程
主动拨号 X] AB[agentBot
MCP 8082 / Admin 8081] OC[opencode 4096] BR ---|127.0.0.1| AB AB --- OC end BR <-->|WSS 长连接| X
  • bridge 与 agentBot 同机部署，由 bridge 主动拨 X，天然穿透 NAT。
  • X 通过同一条全双工链路反向下发任务，agentBot 无需暴露公网。
  • agentBot 的 8081/8082/4096 不对外。

09安全

  • bridge 独立 RSA 身份，公钥登记 X；X 公钥固定到 bridge。
  • X peer policy：只允许 agentId=agentbot、指定 tags、并发、速率、TTL、requireWss。
  • agentBot MCP 仅本机可达并加 Token，不复用飞书凭证。
  • 防环：X 会话 origin/depth 透传到 chat.metadata，bridge 拒绝超深调用。

10失败矩阵

场景行为
X→bridge 链路断P2 outbox 保留，重连 resume 补推；P1 丢未确认结果
bridge 崩溃X 标 interrupted；bridge 恢复后查 taskId 续传
agentBot 崩溃no_task → 默认 failed；可配置一次重试（promptId 防重）
agentBot 队列满回 RATE_LIMITED / BUSY
提问超时agentBot 10min 自动失败；bridge 回 QUESTION_TIMEOUT
取消P1 逻辑；P2 真中断；忽略迟到 done

11测试与里程碑

阶段内容验收
P1MCP-only bridge：能力、open/prompt/poll/done、question、close、逻辑取消X 可把任务交给 agentBot 并拿到结果
P2X v0.2 + bridge 持久化 + 补推断网/重启不丢不重
P3agentBot SSE + cancel_task + 流式 chunk实时输出、真正取消
P4agentBot opencode 加载 X 插件双向互调
最终验收：X 与 agentBot 跨网络互调；任一进程重启/断网后任务最终一致；X 管理台可观测 bridge 会话；P3 后取消能真正终止执行。
