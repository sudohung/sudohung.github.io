X SuperAgent · xagent.md 与远端 Peer 智能路由

X 用 xagent.md 描述自身职能；握手后第一组消息交换节点摘要；路由保留 tag 精确匹配，多命中时由独立的 PeerDecisionModule 调用内部 x-router LLM 选择远端 peer。

01设计结论

节点级描述

xagent.md 代表整个 X SuperAgent，不是单个子 agent；默认只共享 summary。

先 describe 后业务

握手 ACTIVE 后第一组消息是 peer.describe；ready 前拒绝 session.open/prompt。

tag 路由保留

本地/远端精确 tags 继续生效；远端多命中时先 LLM，再最小负载。

独立决策模块

PeerDecisionModule 可替换；当前用固定 x-router profile。

LLM 只选远端

本地选择仍由规则完成；LLM 不参与本地决策。

internal profile

x-router 为 internal + readOnly：不广播、不参与普通路由。

图 4：Peer describe 状态机

stateDiagram-v2 [*] --> WAITING WAITING --> READY: describe 合法 + ack WAITING --> DEGRADED: 超时 / 非法 WAITING --> LEGACY: 对端不支持 describe READY --> WAITING: 重连 READY --> DEGRADED: 版本过期 / 校验失败 DEGRADED --> WAITING: 重试 LEGACY --> WAITING: 对端升级
  • 未 READY 时 session.open/prompt 返回 PEER_NOT_READY（可重试）。
  • describe 超时 5s、重试 3 次；失败只影响 LLM 路由，不影响 tag 路由（若允许 legacy）。
  • 重连重新交换；hash 相同只回 ack。

06决策模块

图 6：AgentPoolDecisionModule 执行与兜底

sequenceDiagram participant R as Router participant D as PeerDecisionModule participant P as AgentPool participant O as opencode(x-router) participant DB as decision_audit R->>D: select(task, candidates, timeout) D->>P: acquire(profileId=x-router, includeInternal) P->>O: createSession + prompt(JSON) O-->>D: message.part / session.idle D->>D: parse + validate JSON alt 有效且置信度达标 D->>DB: write decision D-->>R: {peerId, confidence, reason} else 超时 / 非法 / 低置信度 D->>O: abort D->>DB: write fallback reason D-->>R: null R-->>R: tag / 最小负载兜底 end D->>P: release lease 
interface PeerDecisionModule {
  select(input: PeerDecisionInput): Promise<PeerDecision | null>;
}

interface PeerDecision {
  peerId: string;
  confidence: number;
  reason: string;
}
x-router 约束行为
internal:true不出现在 capability.update，不参与普通路由
readOnly:true只生成决策文本，不执行写操作
maxConcurrency建议 1–2，避免决策抢占业务池
超时默认 4s；失败回退 tag/最小负载
审计记录候选、结果、置信度、耗时、原因

09安全、兼容与测试

不可信描述

限长、schema、控制字符过滤；只用于路由，不作为授权。

防提示注入

descriptor 用分隔符作为数据传入，不拼 system prompt。

只共享 summary

正文、密钥、内部路径不出本机。

无签名/白名单

按当前决策；policy 仍决定能否调用。

legacy peer

不参与 LLM，仅允许 tag 路由（配置控制）。

模块可替换

AgentPool / HTTP LLM / Embedding / Composite。

测试类型覆盖
文件解析、schema、缺失降级、热更新、summary 过滤
协议describe 顺序、ack、ready gating、超时、legacy、重连
决策合法、非法 peerId、低置信度、超时、无候选、提示注入
路由tag 唯一/多命中/无命中；LLM 失败兜底；本地优先
内部 profile不广播、不参与普通路由、可被决策显式获取
验收：握手后先 describe；ready 前不接任务；多 tag 命中先 LLM 再最小负载；x-router 不出现在 peer 能力列表；替换决策实现不影响 Router/协议。
