Templatical · Variable Anchor Design

变量锚点的编辑流程与数据流转

变量在编辑器里是受保护的锚点（chip），不是普通文本。保存草稿时把锚点归一化成 {{key}} 的 token_html；发送前再由 Handlebars 渲染成最终 HTML。

一、编辑阶段：把变量当元素操作

用户不需要、也不允许直接写 {{}}。

1

在正文文本中放置光标

双击文本进入编辑、出现光标后，右侧设置栏底部自动出现 Handlebars 变量面板，同时记录光标所在的 block 与文本偏移；光标消失或点击到正文/侧栏之外时，面板自动收起。

2

第一部分：插入新锚点

填写 key / 类型 / 示例值等信息，点击「插入锚点」即在当前光标处插入一个新变量锚点。

3

第二部分：复用已有变量

已定义的变量按使用次数列出；点击任意一行，会在当前光标处插入锚点并复用该变量 schema。

4

进入变量编辑面板

插入锚点后，或点击正文中的 merge tag chip，面板切换成该变量的编辑态，可修改类型、示例值、默认值和描述。

价格：product.price

chip 不可直接改文本；key 在编辑态只读，避免破坏已插入的锚点。删除变量时会先显示引用次数，二次确认后移除正文中的全部相关锚点并删除变量定义。

5

同一变量可插入多处锚点，也可拖拽调整位置

一个 key 对应一份 schema，正文可以有 N 个 anchor；点击 chip 直接拖拽即可移动，支持同一文本块内和跨文本块拖动。

product.price → a_01product.price → a_07product.price → a_12

6

保存草稿 / 模板快照

design_json 保留锚点；同时保存 variables 和归一化后的 token_html，模板快照再记录 version。

7

用 token_html 预览

预览服务按 schema 的 sample / default 替换 {{key}}，输出最终 HTML；缺少必填示例值时会提示。实际发送时传入真实 values 即可复用同一渲染逻辑。

保护规则：锚点 contenteditable=false；正文里直接输入或粘贴的裸 {{...}} 在保存时会被校验，未知 key 阻止保存。 变量组件不允许挂超链接：选中变量时添加链接会被阻止，保存/载入草稿时会自动移除误加到变量上的链接。 选中变量组件时，上方文本格式工具栏也会隐藏，避免对变量做文本属性操作。

二、保存后的三层数据

设计态、发送态、契约态分开存，互相不污染。

A

design_json

编辑器原生设计数据，保留锚点和位置。

<span data-merge-tag="{{product.price}}" data-label="{{product.price}}">

B

variable_schema

一个 key 一条定义，所有锚点共享。

{
  "product.price": {
    "type": "currency",
    "required": true,
    "sample": 59900
  }
}
C

token_html

唯一发送输入，锚点归一化成 Handlebars token。

<p>价格：{{product.price}}</p>

D

subject / preheader

同样保存 token 模板，发送前一起渲染。

锚点可以有 anchorId，但 token_html 里不出现 ID；ID 只用于设计态定位和“使用位置”统计。

三、发布与发送：从 token_html 到最终邮件

Mailchimp Transactional / SES / Resend / 自研服务只是 Sender adapter。

样例已提供 发送模拟：选择已保存的模板/草稿，填写变量值，渲染并模拟发送。只生成最终 HTML 和本地发送快照，不会真实投递。
Published 模板版本 design_json + schema + token_html
→
Render Service Handlebars 渲染 校验 data → 渲染 subject / preheader / html
→
RenderedEmail 最终 HTML html + text + subject + headers
→
Sender Adapter 投递 Mailchimp Transactional / SES / Resend / 自研
→
Audit 发送快照 data + rendered html + provider id
供应商不解析模板；它只接收最终 HTML。这样换供应商时模板、变量和渲染链路都不变。

六、校验与边界

1

锚点必须引用 schema

不存在于 schema 的 key 不允许保存。

2

裸 token 拦截

正文里手写或粘贴的 {{unknown}} 在保存时报错。

3

key 安全

禁止 __proto__ / constructor / prototype。

4

转义由类型决定

text/currency/url 默认 {{key}}；raw html 才允许 {{{key}}}。

5

锚点 ID 不进 token

Handlebars 只认 key；anchorId 只用于编辑器定位。
